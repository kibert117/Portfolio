# 💬 Telegram-бот (шаблон)

Готовый каркас Telegram-бота на **aiogram 3** + **SQLite**. Бери за основу для заказов:
«бот для приёма заявок», «бот-ассистент», «бот с админкой».

## Что умеет
- `/start` — главное меню с кнопками
- Приём заявок от пользователей → сохранение в БД (SQLite)
- Уведомление админу в личку о новой заявке
- `/admin` — просмотр последних 10 заявок (только для ADMIN_ID)
- FSM-состояние для пошагового ввода

## Структура
- `bot.py` — основной код
- `requirements.txt` — зависимости
- `.env.example` — пример переменных (сделай `.env` из него)
- `bot.db` — создаётся автоматически при запуске

## Установка и запуск
```bash
pip install -r requirements.txt
cp .env.example .env
# впиши BOT_TOKEN (от @BotFather) и ADMIN_ID (свой ID, узнать у @userinfobot)
python bot.py
```

## Как адаптировать под клиента
1. Поменяй тексты в `cmd_start` / `cmd_about` на тему бизнеса.
2. Добавь поля заявки (имя, телефон) — расширь `RequestForm` и таблицу БД.
3. Подключи платежи (CryptoBot / ЮMoney) — добавь хэндлер `pre_checkout`.
4. Добавь рассылку — метод `bot.send_message` по списку из БД.

## Безопасность
- `.env` с токеном — в `.gitignore`, не коммить в публичный репо.
- `ADMIN_ID` ограничивает доступ к `/admin`.
