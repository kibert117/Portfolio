# 🤖 GTA5 Fam Bot

Discord-бот для семейного/кланового сервера GTA5. Написан на **discord.py** (Python).

## Возможности
- Модерация чата: авто-фильтр мата (`BAD_WORDS`), выдача предупреждений
- Система тикетов (`tickets.json`) — обращения участников
- Авто-выдача ролей и проверка прав (`check_permission`)
- Развлекательные команды: шар предсказаний (8-ball), мемы
- Логирование предупреждений (`warnings.json`)

## Структура
- `bot.py` — основной код (команды, ивенты, модерация)
- `requirements.txt` — зависимости (`discord.py`, `python-dotenv`)
- `.env` — токен и настройки (НЕ комить в публичный репо!)
- `tickets.json`, `warnings.json` — файлы данных (создаются автоматически)

## Установка и запуск
```bash
pip install -r requirements.txt
# создай .env:
# TOKEN=твой_токен_бота
# FAM_ROLE_NAME=имя_роли
# FAM_CATEGORY_NAME=имя_категории
python bot.py
```

## ⚠️ Безопасность
Файл `.env` с токеном должен быть в `.gitignore`. Никогда не публикуй токен в открытый репозиторий.
