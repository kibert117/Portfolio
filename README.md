## 🚀 Как запустить каждый проект
Смотри `README.md` внутри каждой папки. Кратко:
```bash
# Бот Discord
cd gta5-fam-bot && pip install -r requirements.txt && python bot.py

# Discord RPC Manager
cd discord-rpc && npm install && npm start

# Игры
cd project1 && pip install pygame && python snake_game.py

# Магазин / Портфолио
открыть index.html в браузере
```
