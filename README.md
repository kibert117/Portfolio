## 🚀 Быстрый запуск

```bash
# Discord-бот
cd gta5-fam-bot
pip install -r requirements.txt
python bot.py

# Discord RPC Manager
cd discord-rpc
npm install
npm start

# Pygame
cd project1
pip install pygame
python snake_game.py
```

> Для ботов нужны собственные токены в `.env`. Никогда не публикуй реальные ключи в репозитории.
