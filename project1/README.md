# 🎮 Pygame Games

Сборник из **6 игр** на Python + pygame. Учебно-практические проекты, демонстрирующие игровой цикл, физику и обработку ввода.

## Состав
| Файл | Игра |
|------|------|
| `snake_game.py` | Змейка (классика) |
| `snake_pro.py` | Змейка Pro (расширенная) |
| `snake_v2.py` | Змейка v2 (другая механика) |
| `rocket.py` | Rocket (аркада) |
| `doom_legacy.py` | DOOM Legacy (топ-даун шутер) |
| `game3.py` | Игра №3 (крупный проект, ~84 КБ) |

## Запуск
```bash
pip install pygame
python snake_game.py   # или любой другой файл
```

## Требования
- Python 3.11+
- pygame 2.6+

Управление — стрелки / WASD (зависит от игры). Все игры запускаются в отдельном окне.
