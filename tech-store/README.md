# 🌐 TechZone Store

Статический интернет-магазин техники. Чистый **HTML / CSS / JavaScript** без фреймворков и сборщиков.

## Возможности
- Адаптивная вёрстка (mobile-first)
- Поиск товаров в реальном времени
- Корзина с сохранением в `localStorage`
- Модальные окна: карточка товара, корзина, личный кабинет, заявка (CTA)
- Личный кабинет с историей заказов
- Отзывы, категории, частицы в hero-секции
- Мобильное меню (бургер)

## Структура
- `index.html` — разметка
- `style.css` — стили
- `script.js` — логика (корзина, поиск, модалки, профиль, отзывы)

## Запуск
Просто открой `index.html` в браузере. Либо подними локальный сервер:
```bash
python -m http.server 8000
# открой http://localhost:8000
```

> Данные корзины/профиля хранятся в `localStorage` браузера. Для реального магазина нужен бэкенд.
